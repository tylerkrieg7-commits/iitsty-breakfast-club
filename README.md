# Iitstys Breakfast Club

The Breakfast Club app and its games, served with GitHub Pages.

- `index.html`: Breakfast Club
- `dungeon-dwellers.html`, `loot-ledger.html`, `color-art.html`, `PocketFarm.html`, `arcade.html`: the games
- `bc-assets.js`: photos, videos and sounds synced from the Photo Manager on the PC
- `piper/`: Piper voices for Dungeon Dwellers (from [piper-tts-web](https://github.com/Poket-Jony/piper-tts-web), MIT)
- `photo-manager/`: the Photo Manager to run on the PC with Docker (see its README.txt)
